# SpeedTree Bridge для Houdini

[English](README.md) · [Скачать v0.5.2](https://github.com/sdomasov269-maker/SpeedTreeHoudiniBridge/releases/tag/v0.5.2) · [Установка](docs/INSTALLATION.ru.md)

<img src="houdini/config/Icons/speedtree_bridge.png" width="80" alt="SpeedTree Bridge">

Импортируйте деревья SpeedTree, создавайте материалы и обновляйте сцену из одного нативного окна плагина внутри Houdini.

**Последний релиз: 0.5.2.** Поддерживаются Arnold, Redshift и Karma, режимы OBJ и Solaris.

![Нативное окно SpeedTree Bridge в Houdini](assets/solaris_general_preview.png)

## Возможности

- Импорт геометрии OBJ / FBX, описаний материалов `.stmat` и текстур.
- Передача сохранённых проектов `.spm` через установленный SpeedTree Modeler: вручную или автоматически после сохранения.
- Обновление того же дерева с сохранением трансформаций, существующих шейдерных правок и пользовательской цепочки SOP.
- Создание Arnold Standard Surface, Redshift Standard/legacy материалов и Karma MaterialX.
- Отдельная сцена Solaris с USD-назначениями материалов, камерой, дополнительным светом и Output выбранного движка.
- Независимые настройки материалов и Solaris-рендера для каждого движка; Karma CPU и XPU.
- Opacity, vertex opacity, отдельные каналы упакованных текстур, normal maps, roughness/gloss, AO и subsurface.
- Автокамера по итоговым границам дерева и формату кадра; перекомпоновка существующей камеры через меню плагина.
- Пакетный импорт нескольких `.stmat`.
- Интерфейс на русском, английском, японском, упрощённом и традиционном китайском.

## Что нового в 0.5.2

В опубликованную версию вошли нативный Live Bridge, Solaris для Arnold / Redshift / Karma, автоматические Output-ноды и вкладки **Общие / Материалы / Рендер / Экспорт**.

Также улучшены импорт и работа с камерой:

- OBJ-дерево SpeedTree автоматически получает поворот **−90° по X**, чтобы стоять вертикально. Преобразование выполняется до создания камеры и сцены USD.
- Камера имеет независимые трансформации и не наследует масштаб или поворот дерева.
- Кадрирование учитывает горизонтальный и вертикальный формат рендера; расстояния отсечения и фокуса рассчитываются по геометрии.
- Размер значков камеры и света подстраивается под размер дерева.
- Команда **SpeedTree Bridge → Reframe Tree / Camera** исправляет старые камеры и ссылки на них в Solaris без повторного импорта меша.
- Повторные живые обновления сохраняют пути нод и пользовательские правки; при ошибке изменения откатываются.

Полная история изменений — в [CHANGELOG.md](CHANGELOG.md).

## Установка

1. Скачайте **SpeedTreeBridge-0.5.2.zip** на [странице релиза](https://github.com/sdomasov269-maker/SpeedTreeHoudiniBridge/releases/tag/v0.5.2).
2. Распакуйте архив в постоянную папку с правом записи.
3. Откройте терминал в распакованной папке и выполните:

```powershell
python install_houdini.py --version 21.0
```

Укажите свою версию Houdini или используйте `python install_houdini.py --all` для всех поддерживаемых папок настроек. Перезапустите Houdini и откройте **SpeedTree Bridge → Open SpeedTree Bridge**.

Отдельная установка Python необязательна: [инструкция](docs/INSTALLATION.ru.md) также описывает установку через Python Source Editor внутри Houdini.

## Работа с плагином

1. Во вкладке **Общие** выберите `.stmat` или сохранённый `.spm`, рендерер и начальный масштаб. Для Solaris выберите **Solaris / USD**; Karma всегда работает через Solaris.
2. Во вкладке **Материалы** настройте шероховатость и нормали. Во вкладке **Рендер** задайте разрешение, сэмплы и путь изображения для Solaris.
3. Для `.spm` во вкладке **Экспорт** выберите SpeedTree Modeler, папку кэша и при необходимости обновление после сохранения.
4. Нажмите **Импортировать / обновить дерево**. Запускайте рендер из созданной ноды в `/out` или откройте сцену в `/stage`.

Геометрия, материалы и Output остаются доступными для редактирования в Houdini. Если после изменения трансформаций или формы дерева нужно заново настроить кадр, выделите дерево либо камеру и выполните **Reframe Tree / Camera**.

## Совместимость

Проверено локально на **Windows, Houdini 21.0.596 и 22.0.368**, со SpeedTree Modeler **10.2**. Адаптеры Python 3 рассчитаны на Houdini 19–22; старые версии требуют дополнительной проверки полного сценария.

Для Arnold и Redshift нужна интеграция под точный build Houdini, включая Hydra-делегат для Solaris. Karma использует установленный движок Houdini. Bridge не включает рендереры, SpeedTree и их лицензии. Живая передача `.spm` требует редакции Modeler с поддержкой экспорта из командной строки.

Поддерживается статическая геометрия. Ветер, анимация, Alembic и автоматический displacement не входят в этот релиз. Визуальная идентичность разных движков не гарантируется. Подробности — в [совместимости и результатах проверок](COMPATIBILITY.md).
