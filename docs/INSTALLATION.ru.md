# Установка — Houdini 19–22

[English](INSTALLATION.md) · [Описание проекта](../README.ru.md)

## 1. Проверьте версии

Нужна сборка Houdini с Python 3.7 или новее. Подключение рассчитано на `19.0`, `19.5`, `20.0`, `20.5`, `21.0`, `22.0`. Сборки с Python 2.7 не поддерживаются.

Проверены Houdini **21.0.596** и **22.0.368**. Для 19/20 подготовлены адаптеры, но полный запуск пока не проверен. Установите Arnold / Redshift, совместимый с точным build вашего Houdini. Bridge не устанавливает рендер-плагины. [Подробности совместимости](../COMPATIBILITY.md).

## 2. Скачайте проект

На GitHub нажмите **Code → Download ZIP**. Распакуйте архив. Найдите папку, в которой находятся `install_houdini.py`, `bridge` и `houdini`, и перенесите её в постоянное доступное для записи место, например:

```text
C:\Tools\SpeedTreeHoudiniBridge
```

Не запускайте файлы внутри ZIP. Не используйте защищённую папку Program Files. Если позже переместите проект, повторите установку, чтобы обновить путь.

## 3. Установите подключение

### Вариант A: через PowerShell и установленный Python

Откройте PowerShell в папке проекта и выполните нужную команду:

| Houdini | Команда |
|---|---|
| 19.0 | `python install_houdini.py --version 19.0` |
| 19.5 | `python install_houdini.py --version 19.5` |
| 20.0 | `python install_houdini.py --version 20.0` |
| 20.5 | `python install_houdini.py --version 20.5` |
| 21.0 | `python install_houdini.py --version 21.0` |
| 22.0 | `python install_houdini.py --version 22.0` |

Для всех шести папок настроек:

```powershell
python install_houdini.py --all
```

Если Python запускается через `py`, используйте `py -3` вместо `python`.

Установщик находит системную папку Documents, включая перенаправление в OneDrive, и записывает только `packages/speedtree_bridge.json`. Другие плагины не заменяются. При повторной установке создаётся резервная копия прежнего package-файла, если такой копии ещё нет.

Если Documents находится в другом месте:

```powershell
python install_houdini.py --version 21.0 --documents "D:\Documents"
```

Если путь настроек Houdini нестандартный, укажите его целиком:

```powershell
python install_houdini.py "D:\MyHoudiniPreferences\houdini21.0"
```

### Вариант B: через встроенный Python Houdini

Отдельный Python не нужен. Откройте Houdini → **Windows → Python Source Editor**. Вставьте и выполните код, заменив путь на свою распакованную папку:

```python
import hou, runpy
installer = runpy.run_path(r"C:/Tools/SpeedTreeHoudiniBridge/install_houdini.py")
print(installer["install"](hou.expandString("$HOUDINI_USER_PREF_DIR")))
```

Подключение установится для запущенной версии Houdini. Сохраните сцену и перезапустите Houdini.

### Вариант C: ручная установка

В Python Shell Houdini получите точный путь к настройкам:

```python
print(hou.expandString("$HOUDINI_USER_PREF_DIR"))
```

В этой папке создайте подпапку `packages`, если её нет. Внутри создайте файл `speedtree_bridge.json`:

```json
{
  "enable": true,
  "env": [
    {"SPEEDTREE_BRIDGE_ROOT": "C:/Tools/SpeedTreeHoudiniBridge"},
    {"PYTHONPATH": {"value": "$SPEEDTREE_BRIDGE_ROOT", "method": "prepend"}}
  ],
  "path": "$SPEEDTREE_BRIDGE_ROOT/houdini"
}
```

Замените путь к проекту. В JSON используйте прямые слеши. Проверьте, что имя заканчивается на `.json`, а не `.json.txt`. Права администратора и изменение установочной папки Houdini не требуются.

## 4. Откройте плагин

Сохраните сцену и перезапустите Houdini. В верхнем меню появится **SpeedTree Bridge → Open SpeedTree Bridge**. На полке **SpeedTree Bridge** также есть кнопка.

Окно открывается по нажатию и не появляется само при запуске. Отдельная программа и ручное подключение моста не нужны. Не устанавливайте PySide через pip в Houdini: окно использует его встроенный Qt.

Если вкладка рендера отключена, соответствующий рендер-плагин не загружен. Уточните версии и установку Arnold / Redshift.

## 5. Первый импорт

1. В SpeedTree экспортируйте OBJ или FBX вместе с `.stmat` и текстурами.
2. Сохраните назначения материалов; для первого теста используйте отдельные, неупакованные карты.
3. Выберите `.stmat` в Bridge. Масштаб задаётся вручную: единицы не угадываются.
4. Выберите движок и галочки камеры / света.
5. Нажмите **Импортировать дерево**. Проверка файлов выполняется перед импортом.
6. Если возникла ошибка, откройте **Подробности**. Для Arnold проверьте новую ноду в `/out` и запустите рендер вручную.

Не перемещайте mesh и текстуры отдельно после импорта: материалы ссылаются на исходные файлы.

## 6. Обновление

Сохраните сцену и закройте Houdini. Распакуйте новую версию в ту же папку. Сохраните `settings.json`, если нужны ваши профили. При установке в новую папку повторно выполните установщик. Затем запустите Houdini.

## 7. Удаление

Закройте Houdini. Удалите только `speedtree_bridge.json` из папки `packages` выбранной версии. Если использовали `--all`, повторите для остальных версий. При следующем запуске плагин отключится. Сцены и уже созданные ноды не удаляются.

## Решение проблем

| Проблема | Что проверить |
|---|---|
| Нет меню | Фактический `$HOUDINI_USER_PREF_DIR`, имя и синтаксис JSON, путь к распакованному проекту; нужен перезапуск |
| Нет полки | Используйте верхнее меню; видимость полок зависит от рабочего пространства |
| Не найден модуль `bridge` | `PYTHONPATH` в package и наличие `bridge/__init__.py` |
| Отключены оба рендера | Версии рендер-плагинов и редакция Houdini, поддерживающая сторонний рендер |
| Не найден mesh или текстура | Пути в `.stmat`; расположение экспортированных файлов |
| Камеру нужно пересчитать | Выделите камеру Bridge → **SpeedTree Bridge → Reframe Selected Camera** |
| Рендер перевёрнут, viewport правильный | Наведите курсор на Render View и нажмите `H`, прежде чем менять дерево |
| Не сохраняются настройки | Доступна ли папка проекта для записи вашим пользователем |

macOS / Linux пока не проверены. Для экспериментальной установки используйте фактический `$HOUDINI_USER_PREF_DIR` и ручной package-файл.
