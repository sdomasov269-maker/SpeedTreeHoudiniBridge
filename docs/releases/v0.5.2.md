# SpeedTree Bridge 0.5.2

Native SpeedTree → Houdini live updates, Solaris workflows and automatic renderer setup.

## Added

- Live transfer of saved SpeedTree Modeler projects from the native Houdini window, including optional updates after saving.
- Solaris integration for Arnold, Redshift and Karma, with USD material bindings and matching render outputs.
- Karma MaterialX materials and CPU/XPU settings.
- General, Materials, Render and Export tabs, with independent renderer profiles.
- Packed texture channels, alpha/vertex opacity, AO and subsurface handling.
- Batch import, cross-platform installer improvements and expanded Python CI coverage.

## Improved and fixed

- Automatic −90° X-axis correction for SpeedTree OBJ trees, applied before camera framing and USD translation.
- Independent camera transforms, correct landscape/portrait framing and geometry-based clipping/focus distances.
- Camera/light guide sizes relative to the tree.
- Reframing of existing tree/camera setups, including Solaris camera targets.
- Stable live node paths, preserved user transforms/shader edits and rollback on failed updates.

## Install

Download **SpeedTreeBridge-0.5.2.zip**, extract it to a permanent writable folder, then run `python install_houdini.py --version 21.0` using your Houdini version. Restart Houdini and open **SpeedTree Bridge → Open SpeedTree Bridge**.

Windows integration checks cover Houdini 21.0.596 / 22.0.368 and SpeedTree Modeler 10.2. Older Houdini adapters and other platforms welcome community validation. Third-party renderers require compatible integrations and licenses.

## Русский

В релиз вошли нативная живая передача SpeedTree → Houdini, Solaris для Arnold / Redshift / Karma, автоматические Output-ноды и отдельные профили настроек.

Исправлены ориентация OBJ-деревьев, наследование трансформаций камеры, кадрирование и ссылки на камеры в Solaris. Поворот −90° по X выполняется автоматически до создания камеры; живое обновление сохраняет пользовательские трансформации и шейдерные правки.

Скачайте установочный ZIP, распакуйте в постоянную папку и выполните `python install_houdini.py --version 21.0`, указав свою версию Houdini. После перезапуска откройте плагин через меню SpeedTree Bridge.
