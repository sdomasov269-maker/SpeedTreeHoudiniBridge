# Совместимость

Диапазон подключения: Houdini 19.0, 19.5, 20.0, 20.5, 21.0, 22.0. На 13 октября 2026 актуальная основная версия — Houdini 22: https://www.sidefx.com/products/whats-new-in-h22/

| Версия | Python / интерфейс | Проверка |
|---|---|---|
| 19.0 / 19.5 | Python 3.7+, Qt 5 / PySide2 | Добавлены адаптеры и установка; полный запуск в этих версиях ещё не проверен |
| 20.0 / 20.5 | Python 3, Qt 5 / PySide2 | Добавлены адаптеры и установка; полный запуск в этих версиях ещё не проверен |
| 21.0.596 | Python 3.11, Qt 6 | Проверяется установленными Houdini, Arnold и Redshift |
| 22.0.368 | Python 3.13, Qt 6 | Проверяется установленным Houdini / Redshift; совместимого HtoA в этой установке нет |

Это поддержка Python 3 сборок Houdini. Альтернативные Python 2.7 сборки Houdini 19 не поддерживаются.

Qt выбирается из hutil.PySide, hutil.Qt, PySide6 или PySide2; для главного окна предусмотрены новый и старый Houdini API. Синтаксис модулей проверен для Python 3.7. Redshift использует StandardMaterial, а при его отсутствии — legacy Material с отдельным сопоставлением параметров. Это не гарантирует одинаковое изображение между версиями Redshift.

Для каждой версии Houdini необходимо установить совместимую с её точным build версию Arnold / Redshift. Bridge не устанавливает и не переносит бинарные рендер-плагины. Недоступные движки отключены во вкладках окна. Для Apprentice ограничения сторонних рендеров сохраняются.

Установка на Windows: `python install_houdini.py --all`. Папка Documents берётся из системных настроек и учитывает OneDrive. Можно указать её явно: `--documents PATH`. Для отдельной версии: `python install_houdini.py PATH_TO_HOUDINI_PREFS`. Новые и старые настройки других плагинов не заменяются.

Полная проверка Houdini 19/20 требует запуска Bridge в этих версиях с установленными рендерами; проверки синтаксиса и адаптеров не заменяют такую проверку.
